1. Introduction & Contexte
1.1 Présentation du Projet
Wijha est une super-app touristique dédiée à l'exploration du Maroc et d'autres destinations. Elle centralise sur une seule plateforme : réservation de vols, hébergements, activités locales, événements culturels et découverte de sites touristiques.
L'ambition est de créer le référentiel digital du tourisme marocain – combinant les fonctionnalités de Booking.com, Airbnb Experiences, Eventbrite et Google Travel – avec une dimension culturelle locale forte et un support natif de la langue arabe (RTL).

1.3 Problématique
Le voyageur souhaitant organiser un séjour au Maroc doit aujourd'hui jongler entre de multiples plateformes :
Vol sur Skyscanner / Expedia
Hôtel ou riad sur Booking.com
Location courte durée sur Airbnb
Activités et expériences sur des blogs ou Airbnb Experiences
Événements culturels sur Eventbrite ou des pages Facebook
Sites à visiter via Google Maps ou guides papier
Cette fragmentation génère de la friction, de la perte de temps et un manque de cohérence dans l'expérience utilisateur. Wijha résout ce problème.

2. Architecture & Stack Technique
2.1 Vue d'Ensemble
L'application repose sur une architecture découplée (decoupled / headless) : le frontend Next.js communique avec le backend Laravel exclusivement via une API REST JSON sécurisée. Chaque domaine métier est encapsulé dans un module Laravel indépendant (Domain-Driven Design).

3. Périmètre Fonctionnel
L'application est structurée autour de 6 modules fonctionnels principaux, chacun correspondant à un pilier de l'expérience voyageur.
3.1 Module Exploration – Places to Visit
Catalogue de destinations : villes, régions, sites naturels, monuments, médinas
Fiches détaillées : photos HD, vidéos, description multilingue, horaires, tarifs
Carte interactive Mapbox avec clustering de POI (hors-ligne possible via cache)
Filtres avancés : catégorie, région, gratuit/payant, accessibilité, saison
Collections thématiques : "Maroc Impérial", "Désert & Dunes", "Côte Atlantique"
Itinéraires suggérés par l'IA : 3 jours à Marrakech, Circuit du Sud, etc.
Contenu généré par les utilisateurs (UGC) : photos, avis, conseils
Fonctionnalité Favoris et listes de voyage collaboratives
3.2 Module Activités – Activities to Do
Équivalent d'Airbnb Experiences : activités proposées par des prestataires locaux vérifiés, réservables en ligne.
Cours de cuisine marocaine, ateliers poterie, calligraphie, zellige
Randonnées guidées (Atlas, Sahara, côte atlantique)
Sports nautiques : plongée, surf, kitesurf, windsurf
Visites guidées de médinas, musées, kasbahs, greniers
Expériences wellness : hammam traditionnel, soins à l'huile d'argan
Photoshoots professionnels dans des lieux iconiques
Profil prestataire vérifié (badge, avis, certifications)
Calendrier de disponibilité temps réel via API Laravel
Réservation instantanée ou sur demande avec gestion groupes (min/max)
3.3 Module Événements – Events to Attend
Agenda culturel complet : festivals, concerts, expositions, marchés
Événements récurrents : Moussem de Tan-Tan, Festival de Fès, Marrakech du Rire

4. Spécifications API REST (Laravel)
4.1 Conventions Générales
Versioning : toutes les routes préfixées par /api/v1/
Format : JSON uniquement (Accept: application/json)
Authentification : Bearer Token via Laravel Sanctum
Pagination : cursor-based (cursor, per_page, next_cursor)
Erreurs : format standardisé { error, message, details, trace_id }
Rate Limiting : 60 req/min pour les endpoints publics, 300 req/min pour les authentifiés
Documentation auto-générée : Scribe → /api/docs (OpenAPI 3.0)

5. Sécurité
5.1 Authentification & Autorisation
Laravel Sanctum : tokens SPA pour le frontend Next.js
OAuth 2.0 via Laravel Socialite (Google, Facebook, Apple)
2FA optionnelle via TOTP (Google Authenticator) ou SMS OTP (Twilio)
Politique RBAC (Role-Based Access Control) : Admin, Partner, User, Guest
Refresh token rotation : access_token (15min), refresh_token (30j)
5.2 Protection des Données
Chiffrement TLS 1.3 pour toutes les communications
Mots de passe hashés avec bcrypt (cost factor 12) via Hash facade Laravel
Données sensibles chiffrées en BDD via laravel-encryption
Conformité RGPD et loi 09-08 marocaine sur la protection des données
Audit de sécurité trimestriel – penetration testing OWASP
Rate limiting et protection DDoS via Cloudflare + Laravel Throttle
Validation stricte de toutes les entrées via Form Requests Laravel
Protection CSRF native Laravel pour les routes SPA
